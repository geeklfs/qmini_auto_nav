# Qmini 台架感知

这套程序跑在 Jetson Nano 上，用已经接好的初代 ZED 做定位、局部障碍和三维重建。开发板还没装到机器人上，所以它只给出建议速度，不驱动电机。

## 这颗摄像头

板上这颗是 Stereolabs 初代 ZED，不是 ZED Mini，也不是 ZED 2。序列号 3858，固件 1142，USB `2b03:f580`。开发板是 Jetson Nano 4GB，JetPack 4.3，ZED SDK 3.5.6。

| 项目 | 参数 |
| --- | --- |
| 传感器 | 左右各一颗 1/3 英寸 400 万像素 CMOS，像元 2 µm，卷帘快门 |
| 基线 | 120 mm |
| 镜头 | f/2.0，对角线视场约 110°。HD2K、HD1080 是裁切后的较窄视场；HD720、VGA 是合并像素后的更广视场 |
| 深度 | 被动双目，32 位浮点，帧率与图像相同 |
| 深度模式 | `PERFORMANCE`、`QUALITY`、`ULTRA`。没有神经网络深度，也没有物体识别 |
| 运动传感器 | 没有 IMU、磁力计、气压计。定位只靠视觉 |
| 接口 | USB 3.0，5 V / 380 mA |
| 机身 | 175 × 30 × 33 mm，约 159 g |

单目分辨率：

| 模式 | 分辨率 | 帧率 |
| --- | --- | --- |
| HD2K | 2208 × 1242 | 15 |
| HD1080 | 1920 × 1080 | 15、30 |
| HD720 | 1280 × 720 | 15、30、60 |
| VGA | 672 × 376 | 15、30、60、100 |

## 探测距离

立体匹配的误差随距离的平方变大。标称最远大约 20 m，近处默认从 0.7 m 算起，SDK 允许收到大约 0.3 m。0.3 m 以内没有可靠深度，程序把这块近距盲区当成危险。

| 用途 | 距离 |
| --- | --- |
| 硬件最近 | 约 0.3 m。更近测不到 |
| SDK 默认最近 | 0.7 m |
| 本程序最近 | 0.4 m |
| 导航采用 | 0.4–5 m。转向射线最远看到 4 m，左右各约 40° |
| 正前方走廊 | 左右各 0.25 m 内的最近障碍，用来判断能不能直行 |
| 障碍高度 | 离地 0.10–1.10 m。更低当成地面，更高先不挡路 |
| 停车 | 膨胀后的净空小于 0.40 m 就停车。车体膨胀半径默认 0.18 m |
| 建图最远 | 8 m，低分辨率、短距离网格 |
| 标称最远 | 约 20 m。5 m 以外噪声大，导航不用 |

在这块 Nano 上，VGA、15 fps、`PERFORMANCE` 深度可以稳定在大约 15 fps。快速转身、白墙和暗光会丢跟踪。地板没有重力参考，只有地面占满画面时才可信。

## 编译

在 Jetson 上：

```bash
cd ~/code/qmini_auto_nav
mkdir -p build && cd build
cmake ..
make -j4
```

## 运行

先确认没有 ZED Explorer 或旧的 ROS 节点占着摄像头。

```bash
cd ~/code/qmini_auto_nav/build
./qmini_auto_nav probe
./qmini_auto_nav nav
./qmini_auto_nav map --seconds 60
```

`nav` 启动后，在电脑浏览器打开：

```text
http://172.16.31.154:8080
```

画面四块：左目、深度、机体坐标系下的局部障碍和转向、世界坐标系下最近约 10 秒的障碍。终端同步打印建议速度。`output/cmd_vel.csv` 是以后接到 Qmini 运动接口的数据，当前没有往电机发送。

建图模式退出时写 `output/mesh.obj`，可以用 MeshLab 打开。`output/obstacles_latest.ply` 是当前帧抽出来的障碍点。

常用参数：

```bash
./qmini_auto_nav nav --res hd720 --fps 15 --camera-height 0.30 --robot-radius 0.18
```

`--camera-height` 只在地板平面没检测到时使用。相机大致水平、光轴朝前时再设这个高度。
